# NOVA Design Assets

This directory contains design references, Figma export tokens, and icon assets.

## Structure

```
design/
├── figma/           # Figma export references and design token JSON
├── icons/           # App launcher icons and notification icons
├── screenshots/     # Device screenshots for README and Play Store
└── mockups/         # UI mockups and wireframes
```

## Design System Reference

All design tokens (colors, typography, spacing, blur, radii) are documented in:
- [`docs/03_Design_System.md`](../docs/03_Design_System.md)
